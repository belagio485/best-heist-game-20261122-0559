Midnight Vault — an original top-down heist game. You are Wren, a thief slipping
through a museum gallery at night: three patrolling guards with vision cones,
two sweeping security cameras, a Star Sapphire on its pedestal, side loot, and
an alarm meter that climbs every second you are seen. Toss coins to lure guards
away, drop smoke to break line of sight, fire an EMP pulse to black out the
cameras — then grab the sapphire and vanish through the skylight exit.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser. No build step, no network
requests: every file the game loads lives under `game/`. Keyboard (WASD/arrows,
Shift to sneak) and mouse (click to toss a coin); Q smoke bomb, E EMP pulse,
R restart, M mute. `?shot=1..4` stages a fixed scene for screenshots.
